# Языковой процессор — лабораторная работа №1

Дисциплина «Теория формальных языков и компиляторов».
Тема: разработка графического интерфейса (GUI) для языкового процессора.

## Цель работы
Сделать оконный текстовый редактор, на основе которого в следующих работах будет строиться языковой процессор — программа для анализа исходного кода.

## О программе
Программа — редактор, в котором можно набрать или открыть текст на C#, запустить его и сразу увидеть результат.
Писать класс и метод `Main` не обязательно: достаточно отдельных строк, например

```csharp
int XYZ = 8+(6-9)*13;
Console.WriteLine(XYZ);
```

Окно разделено на четыре части:
+ главное меню;
+ панель инструментов с кнопками для частых команд;
+ поле ввода текста (с номерами строк);
+ область результатов — только для чтения, на двух вкладках: «Ошибки» и «Вывод программы».

Между полем ввода и областью результатов есть разделитель — его можно тянуть мышью. Размер окна меняется, но меньше 640×420 его не сделать. Полосы прокрутки появляются сами, когда текст не помещается. Внизу окна — строка состояния: что сейчас произошло, где стоит курсор, сколько строк и символов.

## Что умеет программа

### Файл
+ Создать (Ctrl+N) — начать новый текст
+ Открыть (Ctrl+O) — загрузить текст из файла; файл можно и просто перетащить в окно
+ Сохранить (Ctrl+S) — записать изменения в текущий файл
+ Сохранить как (Ctrl+Shift+S) — записать текст в другой файл
+ Выход (Alt+F4) — закрыть программу

Если в тексте есть несохранённые изменения, то при создании, открытии другого файла и выходе программа спрашивает, сохранить ли их: «Да», «Нет» или «Отмена». Несохранённый текст отмечается звёздочкой `*` в заголовке окна.

### Правка
+ Отменить (Ctrl+Z) / Повторить (Ctrl+Y)
+ Вырезать (Ctrl+X), Копировать (Ctrl+C), Вставить (Ctrl+V)
+ Удалить (Del)
+ Выделить всё (Ctrl+A)

### Текст
Пункты «Постановка задачи», «Грамматика», «Классификация грамматики», «Метод анализа», «Тестовый пример», «Список литературы», «Исходный код программы» открывают отдельные окна этих разделов.

### Пуск (F5)
Текст из редактора компилируется как программа на C#.
+ Если есть ошибки — они выводятся на вкладку «Ошибки»: строка, столбец, код ошибки и описание на русском. Щелчок по ошибке переносит курсор к месту ошибки в тексте.
+ Если ошибок нет — программа запускается, а всё, что она напечатала через `Console.WriteLine`, появляется на вкладке «Вывод программы».
+ Непарные скобки `( ) [ ] { }` проверяются отдельно, поэтому вместо нескольких непонятных сообщений компилятора выводится одно: «Лишняя закрывающая скобка» или «Не закрыта скобка».

### Вид
+ Увеличить / уменьшить / вернуть размер шрифта (Ctrl+Плюс, Ctrl+Минус, Ctrl+0, Ctrl+колесо мыши)
+ Перенос строк
+ Номера строк
+ Очистить результаты

Размер шрифта можно выбрать и в списке на панели инструментов.

### Справка
+ Вызов справки (F1) — описание всех функций программы
+ О программе — версия, автор, использованные технологии

### Панель инструментов
Кнопки повторяют команды меню: Создать, Открыть, Сохранить, Сохранить как, Отменить, Повторить, Копировать, Вырезать, Вставить, Удалить, Выделить всё, Пуск, Справка, О программе, Выход. Если навести на кнопку мышь, появится подсказка с названием и горячей клавишей.

## Используемые технологии
+ Язык: C#
+ Интерфейс: Windows Forms
+ Платформа: .NET 7
+ Компилятор для кнопки «Пуск»: Roslyn (пакет Microsoft.CodeAnalysis.CSharp)
+ Среда разработки: Visual Studio 2022

## Сборка и запуск

Готовая программа лежит в `publish/win-x64/LangProcessor.exe`. Это один файл, .NET внутри него уже есть, поэтому на другом компьютере ничего ставить не нужно — достаточно его запустить.

Чтобы собрать из исходников, нужен .NET SDK 7.0 или новее. В Visual Studio достаточно открыть `LangProcessor.sln` и нажать F5. Из командной строки:

```
cd LangProcessor
dotnet restore
dotnet build
dotnet run
```

Собрать один exe-файл, как в папке `publish`:

```
cd LangProcessor
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o ../publish/win-x64
```

## Ограничения
+ Работает только в Windows (Windows Forms).
+ Программа из редактора не может читать ввод с клавиатуры: `Console.ReadLine()` возвращает пустое значение.
+ Если запущенная программа работает дольше 5 секунд (например, зациклилась), выполнение останавливается.
+ Выводятся только ошибки компилятора, предупреждения не показываются.
+ Сообщения об исключениях при выполнении (например, деление на ноль) выводятся на английском — так их выдаёт сама платформа .NET.
+ Первый запуск «Пуска» занимает пару секунд, пока загружается компилятор.
+ Файлы сохраняются в кодировке UTF-8.
